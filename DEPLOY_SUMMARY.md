## 🚀 Как использовать

### Быстрый деплой
```bash
# 1. Настройка переменных
cp env.example .env
nano .env

# 2. Запуск деплоя
./deploy.sh
```

### Пошаговый деплой
```bash
# 1. Генерация SSL сертификатов
./generate-ssl.sh

# 2. Запуск системы
./start.sh

# 3. Проверка статуса
docker ps
```

## 🔧 Управление системой

```bash
# Перезапуск
./restart.sh

# Остановка
docker-compose down

# Логи
docker-compose logs -f

```

## ⚠️ Важные моменты

1. **DNS**: Необходимо настроить A записи для всех доменов
2. **SSL**: Для работы в браузере установите `ssl/ca.crt` как доверенный сертификат
3. **Порты**: Откройте порты 80 и 443 на сервере
4. **Переменные**: Обязательно настройте `.env` файл перед деплоем
